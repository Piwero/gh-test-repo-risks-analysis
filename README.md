# Sample Applications

A collection of small, self-contained sample applications.

| Application | Stack | Path |
|---|---|---|
| Orders API | Python 3.12, FastAPI, SQLAlchemy, SQLite | [`apps/python-fastapi`](apps/python-fastapi) |

Each application lives in its own folder under `apps/` and has its own dependencies, tests and
`README.md` with instructions for running it locally.
